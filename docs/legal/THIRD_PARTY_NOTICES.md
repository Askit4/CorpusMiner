# CorpusMiner - Third-Party Notices and Attribution Guidance

## Research data sources

CorpusMiner may interoperate with data exported by users from third-party academic research platforms, including Scopus and Web of Science.

- Do not imply a partnership, certification, sponsorship, or endorsement unless a written agreement establishes it.
- Use third-party names only as necessary to identify source/provenance or supported import formats.
- Do not bundle third-party logos unless their use is legally/contractually permitted.
- Users remain responsible for source subscription/license restrictions.

## Software dependencies

Before distribution or commercial release:
- generate/review the production dependency list;
- retain required open-source copyright/license notices;
- identify dependencies with attribution, source-disclosure, copyleft, or network-use obligations;
- review fonts, icon packs, charting libraries, and generated assets as well as code libraries.

## AI/model providers

If external AI/model providers are used, document:
- provider and service;
- data categories sent;
- purpose;
- relevant contractual/privacy terms;
- retention/training configuration where available.

Do not describe a model/provider as confidential/private/no-training unless that behavior is supported by the actual account/configuration and terms.

## Brand assets

CorpusMiner and Askit4 production branding must use repository-approved assets under `assets/brand/`.
