# Architecture Decision Records

Registre aquí decisiones técnicas durables que un agente o desarrollador futuro necesitará entender.

Formato sugerido:

```text
0001-use-<decision>.md
0002-<decision>.md
```

Cada ADR debería incluir:

- contexto;
- decisión;
- alternativas consideradas;
- consecuencias;
- fecha;
- estado: proposed / accepted / superseded.
